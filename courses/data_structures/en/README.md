# Data Structures

11 chapter/appendix units with separate teaching material, exercises, and worked solutions.

[Course home](../README.md)

**[Download the full course handout](complete-handout.pdf)** (linked contents, chapter bookmarks, and book page numbers)

Teaching slides are for screen reading. Handouts place the same slides vertically on A4. Exercises and solutions are separate; attempt the exercises before opening the solutions.

Start with ADTs, invariants, and cost models to establish what each operation promises. Arrays, stacks, queues, and linked lists make index and pointer changes concrete. Trees and graphs extend local links into hierarchies and networks; sorting and hashing compare ways to organize and find data. Finish with mergeable heaps, balanced search trees, and external indexes. Chapter 9 retains Chapter 5's heap order but requires separate contracts for meld, handles, and amortized costs. Chapters 10–11 extend the BST interval invariant. Original chapter numbers remain for comparison with Algorithms; conventions and differences are stated where used.

**Themes:** [1. ADTs, correctness, and cost](#contracts-analysis) · [2. Linear structures and pointer operations](#linear-structures) · [3. Trees, graphs, and connectivity](#trees-graphs) · [4. Sorting and hashing](#sorting-hashing) · [5. Mergeable heaps and amortized analysis](#mergeable-heaps) · [6. Balanced search trees and external indexes](#search-indexes)
