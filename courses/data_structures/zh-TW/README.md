# 資料結構

11 個章節／附錄單元，分章提供教材、練習與詳解。

[科目首頁](../README.md)

**[下載整科完整版講義](complete-handout.pdf)**（含目錄、章節書籤及全書頁碼）

播放版適合螢幕閱讀；講義版將同一內容上下排成 A4。練習與詳解各自獨立，建議先作答再開詳解。

先用 ADT、不變量與成本模型釐清每個操作的承諾，再讀陣列、堆疊、佇列與鏈結串列，追蹤索引和指標如何改變。樹與圖把局部連結擴展為階層和網路；排序與雜湊則比較不同的資料查找方式。最後讀可合併堆積、平衡搜尋樹和外部索引。第 9 章沿用第 5 章的 heap order，但 meld、handle 與攤銷成本須各自核對；第 10、11 章延伸 BST 的區間不變量。章號保留，方便對照演算法科的同名主題；採用的慣例與差異在正文相應位置說明。
