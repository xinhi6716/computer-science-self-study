# 遞迴、遞迴式與分治

先用二分搜尋與快速冪掌握遞迴，再學穩定合併排序、遞迴式證明、最大子陣列與矩陣乘法。先跟著數例走過每一步，再回頭理解一般界。

內容涵蓋遞迴規格與終止、任一匹配與首次匹配的差別、參數複製成本、快速冪的精確乘法次數、Fibonacci 的位元成本、穩定 MERGE 與峰值空間、代入法、遞迴樹、主定理及取整證明、非空最大子陣列，以及 Strassen 七個乘積與重組證明。延伸的 Akra–Bazzi 定理列明前提並完整演算應用；一般定理引用來源。
