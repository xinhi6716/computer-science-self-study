# Dynamic Programming

Study states and dependency DAGs, memoization and tabulation, and rod cutting. Continue with 0/1 and unbounded knapsack, LCS and global alignment, matrix-chain multiplication, and optimal binary search trees.

[Teaching slides · 16:9](slides-teaching.pdf) · [A4 handout · two 4:3 panels](slides-handout.pdf)

[29 independent exercises](exercises.pdf) · [Worked solutions](solutions.pdf)

State sufficiency, boundary conditions, reconstruction, tie handling, and update order are explicit. Optimal BST costs distinguish successful and unsuccessful searches; the relevant conventions are compared with the data-structures course.
