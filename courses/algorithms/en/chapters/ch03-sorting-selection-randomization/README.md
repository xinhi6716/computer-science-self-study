# Sorting, Selection, and Randomized Analysis

Study comparison lower bounds, heaps, probability tools, partitioning and quicksort, linear-time sorting, and selection in that order. Finish with collision, load, waiting-time, and online-selection models.

All array procedures use one-based closed intervals unless explicitly stated.
