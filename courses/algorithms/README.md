# 演算法 / Algorithms

從分析方法走到資料結構，再用動態規劃、貪心與圖論練習設計演算法。每章提供播放版、A4 上下兩張講義、獨立練習與詳解。

Original educational notes by Lin Cing for advanced undergraduate and graduate study. Each chapter has separate teaching slides, a two-up handout, exercises, and solutions.

## 閱讀與下載 / Reading and downloads

從語系目錄選章節，或進入章節首頁取得四種 PDF。前四章已依先備知識整合為「分析與正確性」「遞迴與分治」「排序與隨機分析」「資料結構與攤銷分析」；後續主題暫保留原書章號，隨修訂逐步整合。每章檔案位置固定，修訂直接替換，不在公開目錄堆放日期版本。

Choose a language, then a chapter. The first four chapters integrate analysis and correctness, recursion and divide-and-conquer, sorting and randomized analysis, and data structures and amortized analysis. Later topics retain their textbook chapter numbers until revised. Each chapter has four PDF files at stable paths; revisions replace these files rather than adding dated copies.

| PDF | 用途 / Use |
|---|---|
| `slides-teaching.pdf` | 16:9 教用播放，一張一頁 / One slide per page |
| `slides-handout.pdf` | A4 直式上下兩張 / Two slides vertically on A4 |
| `exercises.pdf` | 獨立練習 / Exercises |
| `solutions.pdf` | 完整推導與答案 / Worked solutions |
| `complete-handout.pdf` | 各語系目錄下的整科講義，含目錄與書籤 / Full course handout in each language folder |

## 參考書目 / Reference

- Cormen, Leiserson, Rivest, Stein, *Introduction to Algorithms*, 3rd Edition.
- MIT 6.046J（2004 年 slides、2005 年 lecture notes）；各章列出實際採用的講次與主題。
- Lin Cing 個人手寫筆記：用於章節搭配、推導、圖解與中文敘述；與課本採用不同慣例時，在相關主題說明。

The textbook, MIT course materials, and personal notes are references for the original synthesis. Chapter reference pages identify the material used; the source books and scanned notes are not distributed here.
